_Running the Examples_

To run the examples load the Pace Web Services solution in Visual Studio 2010 and .Net Framework 4.0.
1. Right click on the Project(Pace Web Service SDK) and go to the properties and select the 'Build Event'. 
Notice the 'Pre-build event command line' box is configured to generate the Pace Webservice Client Stub during the build.
Look at the Command '$(ProjectDir)generateStubs_CS_dot.bat Administrator pace localhost' triggers a batch file with 3 arguments.
Change the 3 arguments User Password epaceServer with the your User Password and server respectively.

2. Open the generateStubs_CS_dot.bat file and make sure the path is properly set.

3. Open the file SDK.cs and set same host, port(default 80), username and password.

4. Build the project:
Note that the prebuild event deletes the PaceUtil.cs and recreates the same. PaceUtil.cs is the Pace Webservice Client Stub used to call the Pace Webservice.
Following Webservice Stubs are generated by the prebuild event:  
		http://your.host.com/rpc/services/CreateObject?wsdl
		http://your.host.com/rpc/services/UpdateObject?wsdl
		http://your.host.com/rpc/services/ReadObject?wsdl
		http://your.host.com/rpc/services/CloneObject?wsdl
		http://your.host.com/rpc/services/DeleteObject?wsdl
		http://your.host.com/rpc/services/FindObjects?wsdl
		http://your.host.com/rpc/services/InvokeAction?wsdl
		http://your.host.com/rpc/services/InvokeProcess?wsdl
		http://your.host.com/rpc/services/ReadObject?wsdl
		http://your.host.com/rpc/services/Version?wsdl
		http://your.host.com/rpc/services/InvokePaceConnect?wsdl
		http://your.host.com/rpc/services/GeoLocate?wsdl
		http://your.host.com/rpc/services/SystemInspector?wsdl
		http://your.host.com/rpc/services/FindCompany?wsdl
		http://your.host.com/rpc/services/AttachmentService?wsdl

Once the project is successfully build then it has the Pace Webservice Client Stub (PaceUtil.cs) compitable to your version of Pace Server.

Utilities used to generate the .Net Client Stubs:
disco.exe --> downloads the above mentioned wsdls from your running pace server locally. This API sample project uses the disco.exe from the path you set above.
wsdl.exe --> Creates one client stub file (PaceUtil.cs) from all the above wsdls. This project uses the wsdl.exe from the path you set above.
generateStubs_CS_dot.bat is the batch file which gets triggered in the project pre build event. The batch file ueses the disco.exe to download the wsdl from the Pace server. It generated the stubs using the wsdl.exe and creates a single file for all the generated stubs.
